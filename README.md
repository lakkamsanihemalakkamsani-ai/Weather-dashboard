🌤️ Weather Dashboard

A sleek, modern, and responsive Weather Dashboard template built using pure **HTML**, **CSS**, and **JavaScript**. This dashboard displays current weather details, including temperature, conditions, humidity, wind speed, and a 5-day weather forecast.

📌 Features

Modern Dark UI: Designed with clean typography, rounded card styles, and visual iconography.
City Search: Input field to update the dashboard location dynamically.
Unit Switcher: Toggle easily between Celsius (°C) and  Fahrenheit (°F).
Detailed Weather Metrics: Displays key weather metrics like *Feels like*, Humidity, and Wind speed.
5-Day Forecast Card: Structured forecast grid showing upcoming daily weather conditions and temperature ranges.
Fully Responsive: Adapts seamlessly to Desktop, Tablet, and Mobile screens.

📂 Project Structure

├── index.html   # Main HTML structure
├── style.css    # Styling, layouts, gradients, and responsiveness
└── script.js    # Interactive logic (Unit conversion, search handling)
